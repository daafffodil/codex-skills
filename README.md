# Codex Skills

Reusable Codex skills maintained by daafffodil.

## Available skills

### build-waterfall-report-site

Build or restyle a minimal single-page waterfall-card website for dated reports, intelligence briefs, research archives, project logs, and other structured content.

The skill includes:

- a responsive waterfall-card starter site;
- dated report navigation and calendar selection;
- in-place expandable cards;
- Markdown/JSON content conventions;
- reusable scaffolding scripts;
- Dangdang Yixia brand assets for authorized brand projects.

## Install with Codex

Ask Codex on the target computer:

> Install the skill from `https://github.com/daafffodil/codex-skills/tree/main/build-waterfall-report-site`.

The installed skill becomes available on the next Codex turn.

### project-introduction

Automatically create or update two concise Chinese Markdown files whenever a task produces a real deliverable: a project introduction and a record of the user's observable decisions and requirement evolution.

The skill keeps human problem definition, standards, and judgment distinct from AI-assisted execution. It is designed for project summaries, portfolio descriptions, and reusable project retrospectives.
